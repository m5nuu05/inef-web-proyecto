Bachillerato Técnico Vocacional en Desarrollo de Software

En esta especialidad aprenderás a crear páginas web modernas, programar aplicaciones y diseñar sistemas tecnológicos que facilitan la vida diaria. Te enseñamos a usar herramientas profesionales como HTML, CSS, bases de datos y a trabajar en equipo usando control de versiones con Git y GitHub. No necesitas saber programar desde antes, aquí empezamos desde lo básico para que desarrolles tu creatividad y lógica paso a paso.

Perfil de la Especialidad

Formamos profesionales capaces de desarrollar aplicaciones web y de escritorio, manejar control de versiones con Git/GitHub, y resolver problemas lógicos con lenguajes modernos.
